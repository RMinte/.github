<h2>Local AI, from hardware to applications.</h2>
<p>RMinte develops AI hardware and inference platforms. We bring computing devices, inference engines, and system software together to make local AI easier to deploy, manage, and use — from running models to putting applications to work.</p>
<h2>What we build</h2>
<h3>AI hardware</h3>
<p>Purpose-built computing devices that bring model inference and application workloads to the desktop and the field.</p>
<h3>Inference platforms</h3>
<p>The software layer connecting models with local compute, supporting AI applications and agent workflows.</p>
<h3>Device management & developer tools</h3>
<p>System software, deployment utilities, and documentation for working with the complete device.</p>
<h2>Meet RM-01</h2>
<p><strong>RM-01 · Portable AI Supercomputer</strong></p>
<p>RM-01 brings model inference and application execution into one local platform. Its modular architecture and replaceable CFe-B cards support different model and application setups, with device management built into the system.</p>

<h2>Build with us</h2>

<h3><a href="https://github.com/RMinte-AI/TianshanOS">TianshanOS</a></h3>
<p>Built on ESP32 and ESP-IDF, TianshanOS brings hardware control, monitoring, and maintenance into a unified system. A browser-based interface, command-line tools, and APIs give users and developers access to the device.</p><ul><li><strong>Monitor and control:</strong> temperature and power monitoring, fan control, and power management for connected compute modules.</li><li><strong>Automate operations:</strong> collect device data, evaluate rules, and execute actions to coordinate routine tasks.</li><li><strong>Configure and maintain:</strong> encrypted configuration packs, role-based access, and OTA firmware updates support device administration.</li></ul><p>Read the source, explore the documentation, or contribute fixes and ideas through issues and pull requests. <a href="https://github.com/RMinte-AI/TianshanOS">Explore TianshanOS →</a></p>
