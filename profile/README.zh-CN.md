<h2>从硬件到应用，让 AI 在本地工作。</h2>
<p>泛灵人工智能（ RMinte ）专注于 AI 硬件与推理平台的协同研发。我们将计算设备、推理引擎与系统软件整合为面向实际场景的本地 AI 平台，让模型与应用更容易部署、管理，并融入日常工作。</p>
<h2>我们在做什么</h2>
<h3>AI 硬件</h3>
<p>为模型推理与应用运行设计计算设备，将本地 AI 带到桌面和业务现场。</p>
<h3>推理平台</h3>
<p>连接模型与本地算力的软件基础，支撑 AI 应用与 Agent 工作流程。</p>
<h3>设备管理与开发工具</h3>
<p>提供系统软件、部署工具与文档，帮助开发者使用和管理整套设备。</p>
<h2>认识 RM-01</h2>

<h2>与我们一起构建</h2>
<p>探索我们的开源设备管理系统 TianshanOS，一起完善本地 AI 硬件背后的系统软件。</p>
<h3><a href="https://github.com/RMinte-AI/TianshanOS">TianshanOS</a></h3>
<p>TianshanOS 基于 ESP32 与 ESP-IDF，将硬件控制、状态监测和设备维护整合到统一系统中。用户可以通过浏览器管理设备，开发者也可以通过命令行与 API 接入。</p><ul><li><strong>监测与控制：</strong>温度与电源监测、风扇调节，以及计算模块的电源管理。</li><li><strong>运行自动化：</strong>采集设备数据、判断规则并执行动作，协同处理日常运行任务。</li><li><strong>配置与维护：</strong>通过加密配置包、分级权限和 OTA 固件升级，支持设备的配置与管理。</li></ul><p>欢迎阅读源码与文档，通过 Issue 反馈问题、讨论想法，或提交 Pull Request 参与改进。<a href="https://github.com/RMinte-AI/TianshanOS">探索 TianshanOS →</a></p>
